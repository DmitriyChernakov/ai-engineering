## 1. Zero-shot

 - Что это: _Базовый вид промпта, без примеров._
 - Когда использовать: _Используется для простых и несложных задач, по типу перевода текста или выжимки._

## 2. Few-shot

 - Что это: _Вид промпта с примерами, как правильно обрабатывать задачу._
 - Когда использовать: _Когда модель ошибается или выдает много лишнего текста, а нужен конкретный структурированный вывод по шаблону._

## 3. Chain-of-Thought (CoT)

 - Что это: _Заставляет модель обрабатывать запрос шаг за шагом, выдавая цепочку рассуждений._
 - Когда использовать: _Для математических задач или кода, в планировании или анализе._

## 4. Structured Outputs

 - Что это: _Способ форматирования ответа. Принуждение модели выдать ответ не в виде текста, а, например, в формате JSON._
 - Когда использовать: _Когда нужно использовать результат в коде._

### 2. Few-shot 

```
Определи тональность отзыва. Дай ответ по примеру  
  
Примеры:  
  
Отзыв: "Всё отлично, рекомендую!"

Отзыв: "Ужасный сервис, больше не приду"  
Тональность: Отрицательный  
  
Отзыв: "Обычный товар, ничего особенного"  
Тональность: Нейтральный  
  
  
Классифицируй этот отзыв:  
Отзыв: "Доставка быстрая, но упаковка помята. Сам товар работает отлично."  
Тональность:  
```
  
### 3. Chain-of-Thought (CoT)  

```
Проанализируй отзыв шаг за шагом.  
Сначала выдели плюсы, потом минусы, потом сделай вывод о тональности.  
  
Отзыв: "Доставка быстрая, но упаковка помята. Сам товар работает отлично." 
  
Анализ:  
```
  
### 4. Structured Output 

```
Проанализируй отзыв и верни результат СТРОГО в JSON:  
{  
	"sentiment": "positive|negative|mixed",  
	"pros": [...],
	"cons": [...],
	"confidence": 0.0-1.0
}  
  
Отзыв: "Доставка быстрая, но упаковка помята. Сам товар работает отлично." 
JSON:  
```

### Ответы модели:

Первый прогон:

```
============================================================
Техника: Zero-shot
============================================================
Тональность отзыва можно охарактеризовать как смешанную. Причина этого в том, что отзыв содержит как положительные, так и отрицательные элементы:

1. Положительные аспекты:
   - Доставка быстрая
   - Сам товар работает отлично

2. Отрицательные аспекты:
   - Упаковка помята

Хотя есть негативные моменты, основная оценка товара и доставки положительная, поэтому можно сказать, что это отзыв с преобладающими положительными характеристиками.


============================================================
Техника: Few-shot
============================================================
Тональность отзыва "Доставка быстрая, но упаковка помята. Сам товар работает отлично." можно описать как слегка положительный или положительный с небольшой ноткой негатива.

Причина:
- Быстрая доставка — позитивный момент.
- Товар работает отлично — сильный позитивный момент.
- Упаковка помята — небольшой негативный момент, который не столь значим по сравнению с положительными аспектами.

Таким образом, overall отзыв можно считать положительным, но с некоторой критикой упаковки.


============================================================
Техника: Chain-of-Thought
============================================================
Анализ отзыва:

Шаг 1: Выделение плюсов:
1. Доставка быстрая - клиент оценил скорость доставки товара.
2. Сам товар работает отлично - клиент удовлетворен качеством товара.

Шаг 2: Выделение минусов:
1. Упаковка помята - клиент недоволен состоянием упаковки при получении товара.

Шаг 3: Вывод о тональности отзыва:
Тональность отзыва положительная, но с некоторыми оговорками. Клиент остается доволен основной функциональностью товара и скоростью доставки, однако это не компенсирует его разочарования в качестве упаковки. Общее впечатление можно охарактеризовать как "довольно положительный с небольшими недостатками".


============================================================
Техника: Structured Output
============================================================
{
  "sentiment": "mixed",
  "pros": ["Доставка быстрая", "Товар работает отлично"],
  "cons": ["Упаковка помята"],
  "confidence": 0.8
}

```

## Наблюдения:

В первом прогоне `Few-shot` промпт выглядел так:
```
Определи тональность отзыва.

Отзыв: "Всё отлично, рекомендую!" → Положительный
Отзыв: "Ужасный сервис, больше не приду" → Отрицательный
Отзыв: "Обычный товар, ничего особенного" → Нейтральный
Отзыв: "Доставка быстрая, но упаковка помята. Сам товар работает отлично." →
```

Ответ модели на него ожидался в указанов формате, а пришел свободным текстом. Пришлось явно указать, где примеры и какой отзыв нужно анализировать. После чего во втором прогоне модель справилась гораздо лучше.
