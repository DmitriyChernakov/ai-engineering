
# Заметки
* для вызова модели используется метод `chat()`.
* `messages` - параметр, представленный в виде массива объектов сообщений, каждый из которых имеет роль и содержимое. 
Пример:
```Python
import ollama


response = ollama.chat(
	model='qwen2.5',
	messages=[
		{
			'role': 'user',
			'content': 'Какая столица у Австралии?'
		}
	],
)
```

* `streaming` может быть включен путем установки параметра `stream=True`
Пример:
```Python
import ollama


stream = ollama.chat(
	model='qwen2.5',
	messages=[
		{
			'role': 'user',
			'content': 'Какая столица у Австралии?'
		}
	],
	stream=True,
)
```

* `system prompt` можно установить, передав в метод `chat()` сообщение с ролью `system`, либо использовать метод `generate()`
Пример 1:
```Python
import ollama


system_prompt = "Ты географ, изучающий страны и города всю свою жизнь."

stream = ollama.chat(
	model='qwen2.5',
	messages=[
		{'role': 'system', 'content': system_prompt},
		{'role': 'user', 'content': 'Какая столица у Австралии?'}
	],
)
```

Пример 2:
```Python
import ollama


stream = ollama.generate(
	model='qwen2.5',
	prompt='Какая столица у Австралии?',
	system='Ты географ, изучающий страны и города всю свою жизнь.'
)
```


# Ключевые моменты:

## roles
* `system` - задает системную инструкцию для модели
* `user` - вопрос пользователя
* `assistant` - ответ модели (для истории диалога)

## история диалога
* можно добавлять предыдущие ответы в `messages`
* модель "помнит" конетекст

## streaming
* параметр `stream=True`
* ответ видно сразу, текст печатается по токенам
