
Использование LLM через API вместо локального запуска на своём железе.

## Зачем это нужно
- Локальные модели на моём железе (32ГБ RAM, без GPU) — медленно и нестабильно
- Облако = быстрее, стабильнее, доступ с любого устройства

## Моя конфигурация
- **Провайдер**: OpenAI-совместимый облачный API
- **Чат-модель**: задана в `.env` как `CHAT_MODEL_NAME`
- **Embedding-модель**: задана в `.env` как `EMBEDDING_MODEL_NAME`, размерность **2560**
- **Reranker**: доступен (пригодится для advanced RAG)

## Когда что использовать
| Сценарий                 | Решение                              |
| ------------------------ | ------------------------------------ |
| Обучение, прототипы      | Облачный API                         |
| Kaspi QA Bot (продакшен) | Облачный API                         |
| Приватные данные         | Только локально (если понадобится)   |
| RAG embeddings           | Облачный embedder (размерность 2560) |
