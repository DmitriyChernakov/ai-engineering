# Structured Output: JSON + Pydantic

## Pydantic - ключевые концепции:

 - `Pydantic` - библиотека, проверяющая данные во время выполнения программы
 - `BaseModel` - базовый класс модели данных. Описывает ожидаемую структуру модели
 - `model_dump_json` - валидирует JSON и преобразует его в объект
 - `@field_validator` - декоратор, проверяющий конкретные поля. Может их изменять

## Когда использовать?
 - Когда нужная гарантия структуры
 - Когда результат ответа ИИ идет в код/API/БД
 - Для ИИ агентов

# Вывод

ИИ модель по большей части выдавала тот результат, который от нее и ожидался.

Тесты с промптом без точного диапазона одного из полей были ради эксперимента. И только в 1 из 10 тестов значение этого поля было вне нужного дипазона. Возможно, что диапазон `0.0-1.0` для `confidence` часто используемый в разных данных при обучении модели.

Выдумывание отзывов и других данных можно исправить, явно указав в `system prompt
не выдумывать.
